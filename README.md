# Sunday Supply

A warm, editorial storefront for considered everyday objects. Sunday Supply is built with plain HTML, CSS, and JavaScript—no framework, package installation, or build step required.

## Run locally

1. Open `index.html` in a browser, or serve this folder with any static file server.
2. To use the optional VS Code Live Server extension, right-click `index.html` and choose **Open with Live Server**.

## Features

- Responsive storefront with a mobile navigation menu.
- Animated hero, scrolling message ribbon, and staggered product cards, with reduced-motion support.
- Eight sample products with category filters and live search.
- Interactive favorites and a shopping bag with quantity controls and subtotal.
- Newsletter sign-up interaction for the front-end demo.

## Customize

- Edit the product list, prices, and image URLs in `script.js`.
- Update layout, colors, typography, and animation in `styles.css`.
- Edit page content and sections in `index.html`.

Product photography is loaded from Unsplash, and the display fonts are loaded from Google Fonts, so those assets require an internet connection. The bag and newsletter are front-end demonstrations; checkout and email subscriptions are not connected to a backend.
